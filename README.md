## 它解决什么

外卖平台和菜单上，一屏几十张菜品图挤在一起，顾客只扫一眼。好吃的菜输在三件事上：名字太小、食物不够馋、贴纸贴成一片促销。

**Shop 002** 把画面按顾客的判断顺序排好：**菜名**是第一眼的招牌字，**食物**是绝对中心，**推荐贴纸**帮顾客下判断，小字只负责补充。原稿的口诀是：大字有冲击，贴纸有判断，小字有秩序。

## 你需要准备

- **菜名：** 必需。菜名就是这张图的主角之一。
- **菜品图：** 推荐。摆盘、器皿、配料比例都会照着图保留。没有图也能做，按菜名、地域风味和主料生成。
- **能写上去的事实：** 价格、份量、门店年份、榜单这些，用 `--facts` 写明；没写的不会出现在画面上。

## 推荐贴纸从哪来

| 贴纸 | 谁决定 |
|---|---|
| 招牌、必点、店长推荐、手作、口味签 | 模型按原稿自行生成 |
| 新品、限定、今日特供 | 你说了才有 |
| 热销、人气、口碑、销量、获奖 | 你给了 `--facts` 才有 |

这样做出来的图敢直接挂到平台上，不会因为一句“销量第一”被投诉。

## 快速判断

| 你关心的问题 | 回答 |
|---|---|
| **你会得到什么** | 一张有招牌感、爆品感、记忆点的餐饮主推图 |
| **一眼可辨的特点** | 招牌字级的菜名 · 近景强食欲 · 热气与油润 · 克制的推荐章 · 烟火或清爽的背景 |
| **它不会做什么** | 不缩小菜名、不加你菜里没有的料、不编销量和榜单、不满屏促销 |

## 使用窍门

- **菜名写全：** “藤椒鸡丝凉面”比“凉面”更有招牌感，字体性格也更好选。
- **一张图一道菜：** 原稿要求只突出一个招牌主体，套餐可以分开做。
- **门店语气写进描述：** 偏烟火还是偏精致、是老店还是新潮店，模型会据此选字体和背景。
- **外卖平台优先 1:1，** 门店灯箱和海报用 3:4 或 2:3。

## 开始使用

```bash
git clone https://github.com/nevertoday/xxd-shop-002.git
ln -s "$(pwd)/xxd-shop-002" ~/.claude/skills/xxd-shop-002
```

```text
# 外卖平台主图：菜品图 + 菜名，文字由模型按原稿生成
/xxd-shop-002 ./藤椒鸡丝凉面.jpg --product "藤椒鸡丝凉面" --use 外卖主图 --size 1:1 --text prompt --locale zh-CN

# 没有菜品图，只有菜名和风味
/xxd-shop-002 --product "潮汕牛肉丸粿条汤，手打牛肉丸" --size 1:1,3:4 --text prompt --locale zh-CN

# 带事实的门店灯箱：价格和开店年份由你提供
/xxd-shop-002 ./招牌烤鱼.jpg --product "青花椒招牌烤鱼" --size 2:3 --facts "¥98 / 2–3 人份；2012 年开店" --locale zh-CN

# 一整个菜单图目录，每张图一道菜
/xxd-shop-002 ~/Desktop/新菜单/ --use 外卖主图 --size 1:1 --text prompt --locale zh-CN
```

常用参数：`--product` 菜名 · `--size` 尺寸 · `--count` 每个尺寸几张 · `--text prompt / exact / plan / none` · `--facts` 允许上画面的事实 · `--locale` 文字语言。完整参数见[家族运行合同](references/shop-runtime.md)。

## 边界与信任

- 原始提示词逐字保存，是唯一的审美权威；Skill 只告诉模型这次是哪道菜、哪些事实能写。
- 每道菜在自己的任务里生成，不借用别的菜的名字、贴纸或文案。
- 交付 PNG 位图；每次调用都新建任务目录。
