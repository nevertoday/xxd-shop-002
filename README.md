### 先记住名字，再馋，再下单

<strong>简体中文</strong> · <a href="README.en.md">English</a>

**给每道招牌菜做一张“先记住名字，再馋，再下单”的主推图。**
菜名是招牌大字，食物是绝对中心，推荐贴纸帮顾客做决定。

| 一眼看懂 | |
|---|---|
| **交给它** | 菜名（必需）＋菜品照片（推荐）；价格、份量等想写上去的信息 |
| **你拿到** | 外卖平台主图、菜单图、门店灯箱和海报 |
| **风格特点** | 招牌字级的菜名 · 近景强食欲 · 热气和油润 · 克制的推荐章 · 烟火气或清爽的背景 |
| **最适合** | 外卖平台、点餐小程序、门店灯箱上需要一眼抓人的招牌菜 |

> **装好后，直接这样说：**
>
> /xxd-shop-002 这是我们的藤椒鸡丝凉面，做一张外卖平台主图

## 它解决什么

外卖平台和菜单上，一屏几十张菜品图挤在一起，顾客只扫一眼。好吃的菜往往输在三件事上：名字太小、食物不够馋、贴纸贴成一片促销。

**Shop 002** 按顾客的判断顺序排画面：**菜名**是第一眼的招牌字，**食物**是绝对中心，**推荐贴纸**帮顾客下判断，小字只负责补充。口诀是：大字有冲击，贴纸有判断，小字有秩序。

## 推荐贴纸从哪来

| 贴纸 | 谁决定 |
|---|---|
| 招牌、必点、店长推荐、手作、口味签 | 按菜品自动生成 |
| 新品、限定、今日特供 | 你说了才有 |
| 热销、人气、口碑、销量、获奖 | 你给了真实信息才有 |

做出来的图可以放心挂上平台，不会因为一句没根据的“销量第一”被投诉。

## 你需要准备

- **菜名**（必需）：写全，“藤椒鸡丝凉面”比“凉面”更有招牌感。
- **菜品照片**（推荐）：摆盘、器皿、配料比例都照着保留。没有照片就按菜名、地域风味和主料生成。
- **店的气质**（可选）：烟火小馆还是精致新店，会影响字体和背景。
- **价格、份量、开店年份、榜单**（可选）：说了才会上画面。

## 怎么用

### 第一步：安装（只需一次）

```bash
git clone https://github.com/nevertoday/xxd-shop-002.git
mkdir -p ~/.claude/skills
ln -s "$(pwd)/xxd-shop-002" ~/.claude/skills/xxd-shop-002
```

Codex 用户把同一个文件夹链接到 `~/.codex/skills/xxd-shop-002`。装好后重开一次 AI 助手的会话。

### 第二步：用大白话说出你要什么

```text
/xxd-shop-002 这是我们的藤椒鸡丝凉面，做一张外卖平台主图
/xxd-shop-002 没有照片，菜是潮汕牛肉丸粿条汤，手打牛肉丸，做 1:1 和 3:4 各一张
/xxd-shop-002 招牌烤鱼做门店灯箱，¥98，2–3 人份，2012 年开店
```

不用记参数。没说清的事（比如尺寸、张数），它会一次问齐；第二次用时可以直接沿用上次的设置。

### 第三步：它会这样做

1. 看你的商品图和描述，只问还没定的事；尺寸会按用途推荐比例，并告诉你像素。
2. 每个尺寸都重新构图，不是从一张图裁出来的。
3. 交付前逐张检查：商品有没有被改、字有没有写错、有没有多出你没给的数字。不通过的会告诉你并重做。
4. PNG 存进 `~/Desktop/xxd/xxd-shop-002/` 下新建的任务文件夹，把路径告诉你。

<summary><strong>进阶：命令参数写法（熟练后再看）</strong></summary>

```text
# 外卖平台主图：菜品图 + 菜名，文字由模型按这套风格生成
/xxd-shop-002 ./藤椒鸡丝凉面.jpg --product "藤椒鸡丝凉面" --use 外卖主图 --size 1:1 --text prompt --locale zh-CN

# 没有菜品图，只有菜名和风味
/xxd-shop-002 --product "潮汕牛肉丸粿条汤，手打牛肉丸" --size 1:1,3:4 --text prompt --locale zh-CN

# 带事实的门店灯箱：价格和开店年份由你提供
/xxd-shop-002 ./招牌烤鱼.jpg --product "青花椒招牌烤鱼" --size 2:3 --facts "¥98 / 2–3 人份；2012 年开店" --locale zh-CN

```

## 常见问题

**套餐能做吗？**

一张图只突出一道招牌菜，这样最抓眼。套餐建议每道菜各做一张。

**什么尺寸合适？**

外卖平台优先 1:1；门店灯箱和海报用 3:4 或 2:3。

**需要什么才能用？**

三样东西：① 一个支持 Skills 的 AI 助手，比如 Claude Code 或 Codex；② 一个能出图的模型，可以是助手自带的出图能力，也可以是在 Codex 里配置好的、通过 Responses 接口出图的模型供应商（默认用 GPT Image 2）；③ 电脑上装有 Python 3.11 以上和 Pillow（`pip install pillow`）。

**要花钱吗？能商用吗？**

Skill 本身免费下载，出图费用由你自己的模型账户承担。本项目采用 PolyForm 非商业许可：个人学习、研究、测试可以直接用；用于店铺经营、接单交付等商业用途，需要先取得作者的书面授权，见文末“许可证”。

**出来的图有多大？**

你可以指定比例或准确像素。实际像素以模型返回为准，不会偷偷放大冒充高清，文件名里写的就是真实像素。

**图里的字会写错吗？**

AI 出图偶尔会写错字，或在品牌名旁多出 ® 这类小符号。交付前会逐张放大检查，发现问题就重做那一张；本页的样张都过了这一步。

**会不会乱写价格、销量？**

不会。画面上像事实的内容（价格、规格、产地、销量、获奖、认证……）只来自你提供的信息或商品图上看得清的字；没给就不写，也不放“¥XX”这种占位。

**能一次处理很多商品吗？**

能。把商品图文件夹交给它，每张图当作一件商品，尺寸和文字设置只问一次；每件商品的信息和文案互不串用。

## 它的原则

- **风格不走样：** 这款背后是一份成熟的商业设计提示词（[设计原文](references/original-prompt/zh-CN.md) · [English](references/original-prompt/en.md)）。Skill 不改写它，也不另加配色和美术指导，只把你的商品、尺寸、文字和事实交给模型。
- **商品不改款：** 有商品图时，造型、颜色、包装文字和 Logo 以图为准。
- **只用你给的事实，** 每件商品各管各的，不借用别的商品、旧成品或样张里的内容。
- **交付真实的 PNG 位图，** 不用 SVG 或代码绘图冒充；每次调用都新建任务文件夹。
- 每道菜只在自己的任务里生成，不借用别的菜的名字、贴纸或文案。
