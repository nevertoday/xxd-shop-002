**대표 메뉴마다, 이름이 기억되고 맛이 당기고 주문으로 이어지는 메인 이미지를.**
요리 이름은 간판급 헤드라인, 음식이 화면의 중심, 몇 개의 추천 도장이 손님의 결정을 돕습니다.

| 한눈에 보기 | |
|---|---|
| **맡기는 것** | 요리 이름(필수)과 사진(권장). 가격, 양 등 넣고 싶은 정보 |
| **받는 것** | 배달앱 대표 이미지, 메뉴 이미지, 간판 라이트박스, 포스터 |
| **스타일 특징** | 간판 크기의 요리 이름 · 가깝고 먹음직스러운 음식 · 김과 윤기 · 절제된 도장 · 활기차거나 산뜻한 배경 |
| **가장 잘 맞는 곳** | 배달앱, 주문 미니앱, 매장 라이트박스의 대표 메뉴 |

> **설치한 뒤에는 이렇게 말하면 됩니다:**
>
> /xxd-shop-002 우리 청산초 닭고기 냉면이에요. 배달앱 대표 이미지를 만들어 줘

## 해결하는 문제

배달앱과 메뉴판에서는 수십 장의 음식 사진이 한 화면에 몰려 있고, 손님은 한 번 훑어볼 뿐입니다. 좋은 요리가 지는 이유는 세 가지입니다. 이름이 너무 작고, 음식이 충분히 먹음직스럽지 않고, 스티커를 겹겹이 붙여 싸구려 판촉처럼 보입니다.

**Shop 002**는 손님이 결정하는 순서대로 화면을 배치합니다. **요리 이름**은 간판급 헤드라인, **음식**은 절대적인 중심, **추천 도장**은 판단을 돕고, 작은 글자는 보조만 합니다. 큰 글자로 끌어당기고, 도장으로 판단하게 하고, 작은 글자로 주문하게 합니다.

## 도장은 어디서 오나요

| 도장 | 누가 정하나 |
|---|---|
| 대표 메뉴, 꼭 먹어볼 것, 셰프 추천, 수제, 맛 태그 | 요리에 맞춰 생성 |
| 신메뉴, 한정, 오늘의 추천 | 말했을 때만 |
| 베스트셀러, 인기, 판매량, 수상 | 실제 정보를 줬을 때만 |

그래서 이미지를 그대로 플랫폼에 올려도 안전합니다. 근거 없는 "판매 1위"로 신고당할 일이 없습니다.

## 준비할 것

- **요리 이름**(필수): 줄이지 말고 전부. "냉면"보다 "청산초 닭고기 냉면".
- **사진**(권장): 플레이팅, 그릇, 재료 비율을 그대로 지킵니다. 없으면 이름·지역 맛·주재료로 만듭니다.
- **가게의 성격**(선택): 활기찬 동네 맛집인지 세련된 신생 가게인지. 글자와 배경이 여기에 따라 달라집니다.
- **가격·양·개업 연도·순위**(선택): 줬을 때만 넣습니다.

## 사용 방법

### 1단계: 설치 (한 번만)

```bash
git clone https://github.com/nevertoday/xxd-shop-002.git
mkdir -p ~/.claude/skills
ln -s "$(pwd)/xxd-shop-002" ~/.claude/skills/xxd-shop-002
```

Codex 사용자는 같은 폴더를 `~/.codex/skills/xxd-shop-002`에 링크하세요. 설치 후에는 AI 어시스턴트 세션을 다시 시작합니다.

### 2단계: 원하는 것을 평소 말로 말하기

```text
/xxd-shop-002 우리 청산초 닭고기 냉면이에요. 배달앱 대표 이미지를 만들어 줘
/xxd-shop-002 사진 없음: 차오산 소고기 완자 쌀국수, 손으로 치댄 완자. 1:1과 3:4 한 장씩
/xxd-shop-002 매장 라이트박스용 대표 생선구이: 2~3인분 ¥98, 2012년 개업
```

외울 플래그는 없습니다. 사이즈나 장수처럼 정하지 않은 것은 한 번에 모아서 묻고, 다음에는 지난 설정을 다시 쓸 수 있습니다.

### 3단계: 그다음에 하는 일

1. 상품 이미지와 설명을 읽고 아직 정해지지 않은 것만 묻습니다. 사이즈는 용도에 맞춰 픽셀 크기와 함께 추천합니다.
2. 사이즈마다 새로 구도를 잡고, 다른 이미지에서 잘라내지 않습니다.
3. 납품 전에 한 장씩 확인합니다. 상품이 바뀌지 않았는지, 철자가 맞는지, 주지 않은 숫자가 있는지. 통과하지 못한 것은 알리고 다시 만듭니다.
4. PNG를 `~/Desktop/xxd/xxd-shop-002/` 아래 새 작업 폴더에 저장하고 경로를 알려 줍니다.

## 자주 묻는 질문

**세트 메뉴도 되나요?**

한 장에서 주인공은 대표 요리 하나입니다. 그래야 눈길을 끕니다. 세트라면 요리마다 한 장씩 만드세요.

**어떤 사이즈를 써야 하나요?**

배달앱은 1:1, 라이트박스와 포스터는 3:4 또는 2:3.

**무엇이 필요한가요?**

세 가지입니다. ① Claude Code나 Codex처럼 Skills를 지원하는 AI 어시스턴트. ② 이미지를 생성할 수 있는 모델: 어시스턴트에 내장된 이미지 생성, 또는 Codex에 설정한 모델 제공자로 Responses API를 통해 이미지를 생성하는 것(기본 GPT Image 2). ③ Pillow가 설치된 Python 3.11 이상(`pip install pillow`).

**비용이 드나요? 상업적으로 써도 되나요?**

Skill은 무료로 내려받을 수 있고, 이미지 생성 비용은 본인의 모델 계정에 청구됩니다. 이 프로젝트는 PolyForm Noncommercial 라이선스입니다. 개인 학습·연구·테스트는 괜찮지만, 쇼핑몰 운영, 외주 납품 등 상업적 사용은 먼저 작성자의 서면 허가가 필요합니다. 맨 아래 "라이선스"를 참고하세요.

**이미지는 얼마나 큰가요?**

비율이나 정확한 픽셀을 요청할 수 있습니다. 실제 크기는 모델이 돌려준 그대로이며 몰래 업스케일하지 않고, 파일 이름에 실제 픽셀이 적힙니다.

**이미지 속 글자에 오타가 생기나요?**

AI 이미지는 가끔 철자를 틀리거나 브랜드 이름 옆에 ® 같은 작은 기호를 덧붙입니다. 납품 전에 한 장씩 확대해 확인하고, 통과하지 못하면 다시 만듭니다. 이 페이지의 예시는 모두 그 확인을 통과했습니다.

**가격이나 판매량을 지어내나요?**

아니요. 가격, 사양, 원산지, 판매량, 수상, 인증처럼 사실로 보이는 것은 내가 준 것이나 상품에서 또렷이 읽히는 글자에서만 가져옵니다. 그 밖에는 넣지 않으며 "¥XX" 자리표시도 없습니다.
