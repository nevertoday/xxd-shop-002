# Original XXD Shop 002 style brief

餐饮招牌产品电商主图，高级餐饮商业视觉，围绕“先记住产品名，再产生食欲，再迅速建立购买判断”的逻辑构建画面。

若用户提供菜品图、产品图、包装图或品牌参考图，以其为最高优先级依据，准确保留产品本身的造型、摆盘、结构、器皿、颜色、品牌标识及关键识别特征，不随意改款或替换，只在此基础上重建更高级、更统一、更有销售力的主视觉；若用户未提供图片，则根据菜名、品类、地域风味、核心食材、消费场景与品牌气质自然生成。

画面必须突出一个招牌产品主体，食物成为绝对中心。主体采用强食欲导向的近景或中近景，清楚表现热气、油润感、酱汁、纹理、层次、主料与配料关系，让人第一眼就知道这是店内主推产品。器皿、托盘、桌面、手部或局部场景可适度出现，用来增强真实感、承托感与烟火气，但不能分散主体。

产品名称必须成为第一视觉识别点。大字标题不是普通文案，而是具有招牌感、品牌感和图形感的产品名字体。字形要有清晰轮廓、鲜明个性、强烈记忆点与良好识别度，在缩略图状态下仍能一眼读清。标题与背景之间保持明确反差，让菜名先抓住人，再把注意力引向食物主体。

画面中可自然加入适合该产品的推荐型贴纸、章标、标签或徽记系统，用来强化“招牌、主推、热销、风味、手作、口碑、地域特色、新品、限定、经典、必点、人气”等销售判断。贴纸内容不固定，应根据具体产品属性、品牌语气和消费场景智能生成，数量适度，主次分明，像招牌系统的一部分，而不是满屏促销元素。它们可以是印章感、手写签感、圆标、横幅、小徽章、角标、题签、推荐章或口味签，但必须与整体风格一致，既醒目又不破坏高级感。

辅助文字自然后退，可包括卖点短句、口味说明、地域标签、品牌短语、英文副标或简洁说明，形成清楚的编辑层级。让“大字有冲击，贴纸有判断，小字有秩序”。

背景保持克制，以能烘托产品风味的色彩、空间和气氛建立视觉环境。可以偏浓郁、偏热烈、偏烟火，也可以偏清爽、偏精致，但始终服务于产品名称和食物主体。允许适度出现蒸汽、光晕、桌面材质、传统纹样、地域感符号或手作痕迹，但都应为主体让位。

光线重点服务于“好吃”和“招牌感”。采用具有方向性的柔和光，塑造食物体积、鲜度、热感、光泽与层次，亮部勾起食欲，暗部保留细节，不平均照亮所有元素。让食物诱人，让文字清楚，让贴纸醒目但不过度跳脱。

整体风格应具备：招牌感、爆品感、品牌感、记忆点、销售力。画面要让人一眼知道卖什么，一眼觉得好吃，一眼判断这是值得点的主推产品，并能记住它的名字。

避免：产品名太小、字体无个性、食物不够诱人、贴纸过多过乱、促销感过强、背景过花、信息碎裂、道具堆砌、摆拍感太重、品牌弱化、所有元素同等抢眼。
